## ✨ 뭐가 움직이나요?

### 1. 내 선박 (클린오션-1호) 🚢
- **파란색 큰 마커** + 펄스 효과
- 핫스팟을 순서대로 방문하며 **실제처럼 부드럽게 이동**
- 방향 화살표가 **움직이는 방향으로 회전**
- 이동 경로 **자취 표시** (파란색 점선)
- 속도: 12 knots

### 2. AIS 선박 5척 🚢🚢🚢🚢🚢
각 선박이 **서로 다른 경로**로 움직입니다:

1. **화물선 OCEAN-1** (하늘색)
   - 동쪽으로 이동
   - 속도: 14 knots

2. **어선 해풍호** (초록색)
   - 서쪽으로 지그재그
   - 속도: 8 knots (느림)

3. **여객선 부산스타** (주황색)
   - 북동쪽으로 직진
   - 속도: 18 knots (빠름)

4. **유조선 SEA KING** (분홍색)
   - 남쪽으로 이동
   - 속도: 10 knots

5. **컨테이너선 BLUE WAVE** (보라색)
   - 동쪽으로 이동
   - 속도: 16 knots

### 3. 쓰레기 핫스팟 🎯
- **빨간색** (고위험): 펄스 애니메이션
- **주황색** (중위험): 일반 표시
- **초록색** (저위험): 일반 표시

### 4. 경로 자취 🛤️
- 각 선박마다 **지나온 길**이 점선으로 표시
- 색상은 선박별로 다름
- 일정 길이 이상 되면 자동으로 사라짐

## 🎮 조작 방법

### 기본 조작
- **지도 확대/축소**: 마우스 휠
- **지도 이동**: 드래그
- **현재 위치로**: 📍 버튼 클릭

### 선박 클릭
- 선박 마커를 클릭하면 **상세 정보 팝업**
- 이름, 종류, 속도, 방향 표시

### 핫스팟 클릭
- 좌측 목록에서 클릭 → 지도 자동 이동
- 지도에서 마커 클릭 → 상세 정보

### 레이어 토글
1. 🗂️ 버튼 클릭
2. AIS 선박 / 핫스팟 ON/OFF

## ⚠️ 충돌 경고 시스템

### 작동 방식:
1. 선박 간 거리가 **2km 이내**로 가까워지면
2. 두 선박이 **빨간색으로 깜빡임** (2초간)
3. 콘솔에 경고 메시지 출력

### 확인하는 방법:

## 💡 기술적 특징

### 부드러운 움직임
- **60 FPS** 애니메이션
- `requestAnimationFrame` 사용
- GPU 가속 활성화

### 실제 물리 계산
- **Haversine 공식**으로 거리 계산
- 실제 속도(knots)를 km로 변환
- 방향(bearing) 정확히 계산

### 성능 최적화
- 효율적인 마커 업데이트
- 메모리 관리 (자취 길이 제한)
- 부드러운 전환 효과

A: "TSP 알고리즘으로 가장 효율적인 경로를 계산합니다. 기상 조건도 고려합니다."
