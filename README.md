## 🎯 프로젝트 개요

대한해협(부산 근해)에서 발생하는 부유쓰레기를 효율적으로 수거하기 위한 **실시간 네비게이션 웹 애플리케이션**입니다.
기상 데이터, AIS 어선 데이터, AI 기반 쓰레기 밀집도 예측을 통합하여 최적의 수거 경로를 제공합니다.

### 핵심 목표
- ✅ **안전성**: 실시간 기상 정보 기반 위험 구역 회피
- ✅ **효율성**: A* 알고리즘 기반 최적 경로 계산
- ✅ **시각화**: 직관적인 지도 인터페이스와 다층 레이어 시스템
- ✅ **실용성**: 실제 선박 운항에 활용 가능한 데이터 통합

---

## ✨ 주요 기능

### 1. 🗺️ 실시간 지도 시각화
- Leaflet.js 기반 인터랙티브 맵
- 다중 레이어 시스템 (쓰레기 핫스팟, AIS 어선, 기상 정보)
- 부드러운 애니메이션 및 사용자 친화적 UI

### 2. 🔥 부유쓰레기 밀집구역 히트맵
- **Leaflet.heat** 플러그인 활용
- AI 예측 기반 20개 핫스팟 시각화
- 로그 스케일 정규화로 모든 밀집도 레벨 가시화
- 클릭 가능한 마커로 상세 정보 제공

### 3. 🚢 AIS 어선 추적 및 복잡도 맵
- 실시간 어선 위치 애니메이션
- 어선 밀집도 히트맵
- 충돌 방지 알고리즘

### 4. 🌬️ 실시간 기상 정보 레이어
- **바람**: 풍향/풍속 화살표 시각화
- **파도**: 파고 히트맵 (0.5~2.5m)
- **온도**: 해수면 온도 (21~25°C)
- **가시거리**: 시정 거리 (12~18km)
- 10분 단위 자동 갱신

### 5. 🧭 기상 기반 경로 최적화
- A* 알고리즘 + 기상 비용 함수
- 위험 기상 구역 자동 회피
- 쓰레기 밀집도 우선순위 반영
- 실시간 경로 재계산

## 🚀 설치 및 실행

### 1. 저장소 클론
```bash
git clone https://github.com/your-username/marine_cleanup_nav.git
cd marine_cleanup_nav
```

### 2. 로컬 서버 실행
```bash
# Python 3 사용
python -m http.server 8000

# 또는 Python 2
python -m SimpleHTTPServer 8000

# Node.js 사용 (http-server)
npx http-server -p 8000
```

### 3. 브라우저에서 열기
```
http://localhost:8000
```

또는 [index.html](index.html) 파일을 브라우저로 직접 드래그하여 실행 가능합니다.

## 🎮 사용 방법

### 기본 조작
1. **지도 이동**: 마우스 드래그 또는 화살표 키
2. **줌 인/아웃**: 마우스 휠 또는 +/- 버튼
3. **레이어 관리**: 우측 🗂️ 버튼 클릭

### 레이어 토글
- ✅ **쓰레기 밀집구역**: 히트맵 + 클릭 가능 마커
- ✅ **AIS 복잡도**: 어선 밀집도 시각화
- ✅ **바람 화살표**: 풍향/풍속 + 온도 정보
- ✅ **파도 표시**: 파고 히트맵

### 경로 계산
1. **🧭 기상 기반 경로 계산** 버튼 클릭
2. 시스템이 자동으로 최적 경로 생성
3. 우측 패널에서 경로 정보 확인:
   - 총 거리 (km)
   - 예상 소요 시간
   - 경유지 개수
   - 평균 기상 조건

### 실시간 기상 확인
- 좌측 사이드바에서 현재 위치 기상 정보 실시간 표시
- 🔄 버튼으로 수동 갱신
- 위험 기상 시 자동 경고 표시

## 🧮 알고리즘 상세

### A* 경로 탐색 (기상 반영)

**비용 함수**:
```
f(n) = g(n) + h(n) + w(n)

여기서:
- g(n): 시작점에서 n까지의 실제 거리
- h(n): n에서 목표까지의 추정 거리 (휴리스틱)
- w(n): 기상 비용
```

**기상 비용 계산**:
```javascript
w(n) = windCost + waveCost

windCost = (wind_speed / 10)² × 0.3
waveCost = (wave_height / 2)² × 0.4

// 위험 구역 (풍속 > 20 m/s 또는 파고 > 3.5 m)
if (위험 구역) w(n) += 9999  // 거의 통과 불가
```

### 파고 추정식

풍속 기반 파고 추정 (Bretschneider 공식 변형):
```javascript
H ≈ 0.21 × V^1.5 / 9.8

여기서:
- H: 파고 (m)
- V: 풍속 (m/s)
```

### 핫스팟 우선순위 점수

```javascript
score = priority_weight - distance × 2

priority_weight:
- high (위험도 높음): 100점
- medium (위험도 중간): 50점
- low (위험도 낮음): 20점
```

### 로그 스케일 정규화 (히트맵)

```javascript
normalized = Math.log10(value + 1) / Math.log10(maxValue + 1)

// 작은 값도 시각화되도록 로그 스케일 적용
```

## 🐛 문제 해결

### Q: 히트맵이 안 보이면?
**A**:
1. 레이어 패널(🗂️)에서 "쓰레기 밀집구역" 체크
2. 줌 레벨 확인 (11~15 권장)
3. 브라우저 콘솔(F12)에서 에러 확인

### Q: 경로 계산이 실패하면?
**A**:
1. 기상 데이터가 로드되었는지 확인
2. 핫스팟 데이터 로드 상태 확인
3. 브라우저 콘솔에서 에러 메시지 확인

### Q: 애니메이션이 느리면?
**A**:
1. 레이어를 일부 비활성화
2. 하드웨어 가속 활성화 (Chrome 설정)
3. 줌 레벨 조정
