## 💡 주요 함수 목록

### app.js
- `initMap()` - 지도 초기화
- `addHotspotMarkers()` - 핫스팟 마커 추가
- `addAISMarkers()` - AIS 마커 추가
- `optimizeRoute()` - 경로 최적화
- `updateAllData()` - 데이터 업데이트

### utils.js
- `calculateDistance()` - 거리 계산
- `calculateBearing()` - 방향 계산
- `formatDistance()` - 거리 포맷팅
- `calculateETA()` - 도착 시간 계산
- `showErrorAlert()` - 에러 알림
- `exportToCSV()` - CSV 내보내기

### config.js
- `validateConfig()` - 설정 검증
- `saveConfig()` - 설정 저장
- `loadConfig()` - 설정 불러오기
- `isAPIEnabled()` - API 활성화 확인
