# AIS 경로 시각화 및 분석

## 1. 개발 배경 및 목적

해양쓰레기 수거 작업 시 어선 조업 활동과의 충돌을 방지하고 안전한 운항 경로를 확보하기 위해, AIS(Automatic Identification System) 데이터를 활용한 어선 경로 시각화 및 분석 시스템을 개발하였다. 본 시스템은 실시간 어선 위치 데이터를 기반으로 시간대별·날짜별 어선 활동 패턴을 분석하여 수거선의 최적 운항 시간과 경로를 제시한다.

---

## 2. 개발 기능

### 2.1 데이터 로드 및 전처리 기능

**기능 설명:**
- 7가지 조업 유형(자망, 안강망, 채낚기, 연승, 통발, 트롤, 선망)의 AIS 데이터를 CSV 파일 형식으로 자동 로드
- 각 조업 유형별로 사용자가 지정한 개수만큼의 파일을 샘플링하여 처리
- datetime, 위치(위도/경도), 속도(SOG), 조업 유형 등의 데이터를 통합 및 정규화

**주요 특징:**
- 대용량 데이터 처리를 위한 샘플링 기능 제공
- 실시간 진행 상황 표시로 사용자 편의성 향상
- 데이터 요약 정보(총 포인트 수, 기간, 공간 범위) 자동 출력

**처리 결과 예시:**
```
총 데이터 포인트: 70,560개
조업 유형: 7개
기간: 2020-01-01 ~ 2020-09-09
위도 범위: 32.5559° ~ 36.9526°
경도 범위: 126.4533° ~ 130.2847°
```

---

### 2.2 인터랙티브 경로 시각화 기능

**기능 설명:**
Folium 라이브러리를 활용하여 웹 기반 인터랙티브 지도를 생성하며, 다음과 같은 레이어 구조를 제공한다.

**2.2.1 전체 경로 레이어**
- 모든 어선의 이동 경로를 조업 유형별 색상으로 구분하여 표시
- 각 경로를 클릭하면 상세 정보 팝업 제공:
  - 조업 유형
  - 총 포인트 수
  - 시작/종료 시간
  - 평균 속도 및 최대 속도

**2.2.2 날짜별 필터링 레이어**
- 최대 15일간의 데이터를 날짜별로 분류
- 레이어 컨트롤 패널에서 특정 날짜를 체크/해제하여 해당 날짜의 어선 활동만 선택적으로 확인 가능
- 날짜별 경로 비교를 통해 요일별 조업 패턴 분석 가능

**2.2.3 시간대별 필터링 레이어**
- 24시간을 4개 구간으로 분류:
  - 🌙 심야 (00-06시)
  - 🌅 새벽 (06-12시)
  - ☀️ 오후 (12-18시)
  - 🌆 저녁 (18-24시)
- 각 시간대별 어선 위치를 마커로 표시
- 마커에 마우스를 올리면 **툴팁으로 정확한 시간과 속도 정보** 표시
- 마커 클릭 시 상세 정보(시간, 속도, 조업 유형, 정확한 위치 좌표) 팝업

**2.2.4 밀집도 히트맵 레이어**
- 어선 활동이 밀집된 해역을 색상으로 시각화
- 색상 그라데이션:
  - 파랑(Blue): 안전 - 어선 활동이 거의 없는 구역
  - 초록(Lime): 주의 - 어선 활동이 소수인 구역
  - 노랑(Yellow): 경계 - 어선 활동이 보통인 구역
  - 빨강(Red): 위험 - 어선 활동이 밀집된 구역
- 수거선 경로 계획 시 빨간색 구역 회피 가능

**조업 유형별 색상 코드:**
- 자망: 빨강(#FF4444)
- 안강망: 파랑(#4444FF)
- 채낚기: 초록(#44FF44)
- 연승: 보라(#FF44FF)
- 통발: 주황(#FFAA44)
- 트롤: 진한 빨강(#AA4444)
- 선망: 진한 파랑(#4444AA)

### 2.3 시간대별 안전도 분석 기능

**기능 설명:**
24시간을 각 시간대별로 분석하여 수거선 운항의 안전도를 0-100점 척도로 평가한다.

**안전도 점수 계산 방식:**
```
안전도 점수 = 100 - (어선 밀집도 × 0.7 + 평균 속도 × 3)
```
- 어선 밀집도: 해당 시간대의 전체 데이터 대비 어선 수 비율
- 평균 속도: 해당 시간대 어선들의 평균 이동 속도(knots)

**안전도 등급 분류:**
- 매우 안전: 70점 이상
- 안전: 50-70점
- 주의: 30-50점
- 위험: 30점 미만

**분석 결과 예시:**
```
안전한 시간대 TOP 5:
1. 02:00 - 안전도 85/100 (매우 안전)
2. 03:00 - 안전도 83/100 (매우 안전)
3. 04:00 - 안전도 81/100 (매우 안전)
4. 01:00 - 안전도 78/100 (매우 안전)
5. 05:00 - 안전도 76/100 (매우 안전)

주의 시간대 TOP 5:
1. 10:00 - 안전도 28/100 (위험)
2. 11:00 - 안전도 30/100 (주의)
3. 09:00 - 안전도 32/100 (주의)
4. 14:00 - 안전도 35/100 (주의)
5. 15:00 - 안전도 37/100 (주의)
```

**활용 방안:**
- 심야~새벽 시간대(00-06시)가 가장 안전한 것으로 분석됨
- 오전~오후(08-16시)는 조업 활동이 활발하여 수거선 운항 시 각별한 주의 필요
- 안전도 60점 이상 시간대를 우선적으로 수거 작업 스케줄에 배정

---

### 2.4 통합 정보 패널 기능

**기능 설명:**
지도 우측 하단에 고정된 정보 패널을 통해 실시간으로 주요 정보를 제공한다.

**패널 구성 요소:**

**① 데이터 요약 섹션**
- 총 데이터 포인트 수
- 분석된 조업 유형 수
- 분석 기간(일 수)

**② 안전한 시간대 TOP 5**
- 안전도 점수가 높은 상위 5개 시간대
- 각 시간대별 안전도 점수 및 등급 표시

**③ 주의 시간대 TOP 5**
- 안전도 점수가 낮은 하위 5개 시간대
- 수거 작업 시 회피해야 할 시간대 정보

**④ 조업 유형별 통계**
- 각 조업 유형별 데이터 포인트 수
- 색상 범례로 지도상 경로 식별 지원

**⑤ 사용 방법 안내**
- 레이어 선택 방법
- 인터랙션 기능 설명
- 히트맵 활용 방법

---

### 2.5 보고서용 통계 정보 출력 기능

**기능 설명:**
콘솔에 보고서 작성에 필요한 통계 정보를 구조화된 형식으로 출력한다.

**출력 정보:**

**1. 데이터 개요**
- 총 AIS 데이터 포인트 수
- 분석 조업 유형 수
- 분석 기간
- 공간 범위(위도/경도 최소-최대값)

**2. 조업 유형별 활동량**
- 각 조업 유형별 데이터 포인트 수
- 전체 대비 비율(%)

**3. 시간대별 안전도 분석**
- 최고 안전 시간대 TOP 3
- 주의 시간대 TOP 3
- 각 시간대별 안전도 점수 및 등급

**4. 권장 운항 시간**
- 안전도 60점 이상인 모든 시간대 목록
- 안전 시간대 총 개수

## 3. 시스템 아키텍처

### 3.1 기술 스택
- **언어:** Python 3.x
- **데이터 처리:** pandas, numpy
- **지도 시각화:** folium, folium.plugins
- **파일 시스템:** pathlib

### 3.2 주요 클래스 구조

**AISNavigationSystem 클래스**
```python
class AISNavigationSystem:
    - __init__(base_path): 시스템 초기화
    - load_data(limit_files): 데이터 로드 및 전처리
    - analyze_time_safety(): 시간대별 안전도 분석
    - create_comprehensive_map(): 통합 지도 생성
    - generate_report_summary(): 통계 정보 출력
```

### 3.3 데이터 구조
```python
주요 컬럼:
- datetime: 날짜 및 시간 (YYYY-MM-DD HH:MM:SS)
- lat: 위도
- lon: 경도
- sog: 대지 속도(Speed Over Ground, knots)
- folder: 조업 유형
- file: 원본 파일명
- vessel_type: 조업 유형명(한글)
- time_hour: 시간(0-23)
- weekday: 요일
```

## 4. 사용자 인터페이스

### 4.1 메뉴 구조
```
[1] 통합 네비게이션 지도 생성 (날짜/시간 필터링)
    → ais_navigation_system.html 파일 생성
    
[2] 보고서용 요약 정보
    → 콘솔에 통계 정보 출력
    
[3] 모두 생성 (지도 + 요약)
    → 지도 파일 생성 + 통계 정보 출력
    
[0] 종료
```

### 4.2 지도 인터랙션 기능

**레이어 컨트롤 (우측 상단)**
- 📅 날짜별 레이어: 특정 날짜 선택
- 🌙 시간대별 레이어: 4개 시간대 구간 선택
- 🚢 전체 경로: 모든 경로 표시/숨김
- 🔥 밀집도 히트맵: 히트맵 표시/숨김

**경로 클릭**
- 팝업 창 표시
- 조업 유형, 포인트 수, 시작/종료 시간, 속도 정보 제공

**마커 마우스 오버**
- 툴팁으로 시간과 속도 즉시 표시
- 예: "14:35 - 3.2kt"

**마커 클릭**
- 상세 정보 팝업
- 정확한 날짜/시간, 속도, 조업 유형, 위치 좌표

## 5. 실행 방법

### 5.1 실행 명령
```bash
python ais_navigation_final.py
```

### 5.2 데이터 로드 설정
```
각 조업 유형당 로드할 파일 수: 10-15 (권장)
```
- 적은 수(5개): 빠른 테스트용
- 권장 수(10-15개): 충분한 데이터 + 적절한 처리 속도
- 많은 수(20개 이상): 상세 분석용 (처리 시간 증가)

### 5.3 출력 파일
```
C:/Temp/ais_navigation_system.html
```
- 웹 브라우저로 열기
- 모든 인터랙티브 기능 사용 가능
- 확대/축소/이동 자유롭게 가능

## 6. 활용 예시

### 6.1 수거선 운항 계획 수립

**시나리오:** 특정 날짜에 해양쓰레기 수거 작업 계획

**절차:**
1. 지도 로드 후 해당 날짜 레이어만 선택
2. 히트맵 레이어 활성화하여 밀집 지역 확인
3. 시간대별 레이어를 순차적으로 확인하여 안전한 시간대 파악
4. 정보 패널의 안전 시간대 TOP 5 참조
5. 빨간색(위험) 구역을 회피하는 경로 계획

**결과:**
- 심야 시간대(02-05시) 운항 시 충돌 위험 최소화
- 밀집도가 낮은 파란색 구역을 통과하는 경로 선택
- 안전하고 효율적인 수거 작업 수행

### 6.2 시간대별 위험도 비교

**시나리오:** 오전과 오후 중 언제 운항할지 결정

**절차:**
1. "새벽(06-12시)" 레이어 활성화 → 마커 밀집도 확인
2. "오후(12-18시)" 레이어 활성화 → 마커 밀집도 확인
3. 정보 패널에서 각 시간대별 안전도 점수 비교

**결과:**
- 새벽 시간대가 오후보다 안전도 점수 약 40점 높음
- 새벽 시간대 운항 권장

### 6.3 조업 유형별 활동 패턴 분석

**시나리오:** 특정 조업 유형과의 충돌 위험 평가

**절차:**
1. 정보 패널에서 조업 유형별 데이터 포인트 수 확인
2. 색상 범례를 참고하여 지도에서 해당 색상 경로 추적
3. 특정 조업 유형이 밀집된 시간대와 해역 파악

**결과:**
- 자망(빨강) 경로가 새벽 시간대에 남해안에 집중
- 트롤(진한 빨강) 경로가 오후 시간대에 동해안에 집중
- 조업 유형별 특성을 고려한 회피 전략 수립

## 8. 결론

본 AIS 경로 시각화 및 분석 시스템은 어선 조업 활동 데이터를 효과적으로 시각화하고 분석하여, 해양쓰레기 수거선의 안전한 운항을 지원하는 도구이다. 

날짜별·시간대별 필터링 기능을 통해 사용자가 원하는 조건의 데이터만 선택적으로 확인할 수 있으며, 경로와 마커에 마우스를 올리면 즉시 시간과 속도 정보를 확인할 수 있어 직관적인 사용이 가능하다.

특히 시간대별 안전도 분석 기능은 수거 작업의 최적 시간을 과학적으로 제시하며, 히트맵을 통한 밀집도 시각화는 위험 해역을 한눈에 파악할 수 있게 한다.

향후 실시간 AIS 데이터 연동, 기상 정보 통합, AI 기반 자동 경로 추천 등의 기능을 추가하여 더욱 고도화된 네비게이션 시스템으로 발전시킬 예정이다.
